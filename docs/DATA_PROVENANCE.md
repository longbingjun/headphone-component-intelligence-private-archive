# Data provenance

This repository is a fixed, sanitized portfolio demonstration. It is not a mirror of any source website and it does not run scheduled collection on GitHub Pages.

## Processing chain

1. Public teardown articles or video clues are identified outside the public demo build.
2. Product identity, component, manufacturer, model, parameter and usage-location facts are extracted.
3. Brand and supplier aliases are normalized while the original evidence relationship is retained.
4. A human-reviewed, small subset is exported as structured JSON.
5. The public site generates product, component, supplier and brand views from that fixed snapshot.

The public repository contains eight real demonstration cases. Each case keeps a source URL for attribution and verification, but does not distribute source images, full articles or transcripts.

Aggregations and rankings describe only this demonstration snapshot. They do not estimate market share, purchase volume, shipment volume or the complete product range of a supplier.
