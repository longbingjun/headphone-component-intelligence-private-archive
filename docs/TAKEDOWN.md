# Correction and takedown

If you are a rights holder or identify incorrect attribution, personal information, confidential information or content that should not appear in this demonstration, open a repository issue with:

- the affected page or record;
- the original source URL;
- the requested correction or removal;
- a way to verify the request when ownership is relevant.

Validated requests will be handled by correcting the structured fact, replacing it with a source link only, or removing the affected record from the public snapshot.
